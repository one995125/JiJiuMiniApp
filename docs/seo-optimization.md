# 小程序搜索优化记录

## 当前定位

记酒是一款面向成年人朋友聚会的惩罚公平记账小程序。用户可添加参与人员，按杯、瓶、罐记录增加和完成数量，查看每个人的待完成数；饮料、积分或其他友好方式同样能记。

## 搜索承接页面

- 首页：`pages/index/index`
- 搜索介绍页：`pages/landing/landing`
- 记酒页：`pages/record/record` 不参与收录，因为它属于用户临时聚会状态页。

## 核心关键词

- 聚会记账
- 划拳计数
- 惩罚计数
- 待完成排行
- 朋友游戏计数
- 记酒

这些词已自然放入首页首屏、搜索介绍页标题、功能说明、FAQ、分享标题和朋友圈标题中。避免隐藏堆词，优先让用户进入后能马上理解产品用途。

## 微信后台检查项

1. 在小程序后台确认“页面收录”已开启。
2. 上传版本后，在开发者工具控制台检查 sitemap 索引提示。
3. 关注微信搜索来源词，如果持续出现新的高转化词，再扩展 `pages/landing/landing` 的 FAQ 文案。
4. 搜索结果曝光稳定后，再考虑新增更细的专题页，例如“划拳惩罚计数工具”“朋友聚会公平记账”。
